# Cruna plugins

Public plugins by [Cruna](https://crunasignal.com) for Claude and ChatGPT, in English and Italian.

| Plugin | Language | What it does |
|---|---|---|
| [agora](cruna-plugin-eng/agora/) | English | A shared, AI-kept knowledge base on Google Drive and Calendar for families and small teams |

## Install

**Claude**

```
/plugin marketplace add Cruna-Noise-To-Signal/cruna-plugins
/plugin install agora@cruna-plugins
```

**ChatGPT**: install the plugin from the Plugins page. In a workspace, an admin installs and publishes it first.
